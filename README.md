# Israel Chaves — Portfólio

Portfólio pessoal com identidade visual renovada, inspirado em interfaces modernas de tecnologia e IA.

## Tecnologias
- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

## Estrutura
- `index.html` — estrutura da página
- `meu.css` — identidade visual, layout e responsividade
- `meu.js` — navegação, animações e interações
- `img/` — imagens dos projetos e perfil
